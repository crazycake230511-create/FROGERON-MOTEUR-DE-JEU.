🐸 FROGERON EDITOR
Glisse pour tourner · pince pour zoomer · touche un objet pour le sélectionner

Prototype mobile : ajoute des formes, importe ta grenouille, ajuste sa position et sa taille, puis exporte la scène en GLB. Les projets sont stockés dans ton navigateur uniquement si tu les exportes.

Pour garder les textures, privilégie un fichier GLB avec les textures intégrées. Les fichiers OBJ/FBX ne sont pas pris en charge dans cette première version.

Les couleurs sont appliquées aux matériaux simples. Pour un modèle texturé, la texture d'origine est conservée sauf si tu appliques volontairement une couleur.

Cette sauvegarde conserve les objets primitifs, leurs transformations et couleurs. Les modèles importés doivent être réimportés après rechargement de cette sauvegarde dans cette version prototype.

Prêt. Aucun projet envoyé sur un serveur.
